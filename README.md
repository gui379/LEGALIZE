# LEGALIZE

**Plataforma de Automação e Gestão de Contratos Jurídicos**

O LEGALIZE é um projeto acadêmico desenvolvido com o objetivo de facilitar a criação, organização e gerenciamento de contratos jurídicos por meio de uma plataforma web.

## Sobre o projeto

A plataforma busca tornar a gestão contratual mais acessível, organizada e eficiente, oferecendo recursos para auxiliar usuários na elaboração e no acompanhamento de documentos jurídicos.

## Tecnologias utilizadas

- Python
- Django
- HTML, CSS e JavaScript
- SQLite (banco de dados de desenvolvimento)

## Funcionalidades

- Cadastro e autenticação de usuários.
- Criação e gerenciamento de contratos.
- Geração de documentos em PDF.
- Histórico e organização de contratos.
- Interface web para acesso às funcionalidades.

## Como executar o projeto

**1. Instale as dependências:**

```bash
pip install -r requirements.txt
```

**2. Prepare o banco de dados:**

```bash
python manage.py migrate
```

**3. Inicie o servidor:**

```bash
python manage.py runserver
```

**4. Acesse no navegador:**

http://127.0.0.1:8000/
